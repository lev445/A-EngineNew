## Итак, пока я спал, я придумывал архитектуру для проекта и как он будет работать.

Классы:
Будет спец. формат файла под названием .asc (a+ engine scene main) в котором описывается почти что все:

-- все entity
-- все не живые объекты
-- карты
Также будет формат файла .asa (a+ engine scene archive) в котором хранятся как раз таки все .asc. Сборщик просматривает любой фаайл .asc, если он видет подключение:
```asc
connect: alsofile.asc
class Entity0 {
	// ...
}
end
```
То он упаковывает его в архив: .asa.

НО! Главное меню также можно будет редактировать, но его можно будет редактировать в другом файле.
.ams (A+ engine main scene) это по сути xml файл, но с осбой структурой.
```ams
<?xml version="1.0" encoding="UTF-8"?>
<mainmenu>
   <!-- в категории prop хранится полная информация о меню. -->
   <prop>
      <!-- самый большой шрифт (титл) -->
	  <title>A+ Engine Main Scene</title>
	  <!-- подтитл -->
	  <game>A+ Engine</game>
	  <!-- это кнопка. x,y - это координаты кнопки в 2D. connect привязывает кнопку к функции -->
	  <button>New Game</button x,y connect=New_Game>
   </prop> 
</mainmenu>
```
